# Iron Arena

A browser arena shooter.

- **Play online:** https://mahadupdalla.github.io/iron-arena/
- **Android:** download [IronArena.apk](https://mahadupdalla.github.io/iron-arena/android/IronArena.apk) and install it on your phone (allow installs from unknown sources).

Files:
- `index.html` – the current game (works on phones with touch controls, and on desktop)
- `classic.html` – desktop-only version
- `v1-orbs.html` – earlier version
- `android/source` – Android wrapper source
