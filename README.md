# Iron Arena

A browser arena shooter.

- **Play online:** https://mahadupdalla.github.io/iron-arena/
- **Android:** download [IronArena.apk](android/IronArena.apk) and install it on your phone (allow installs from unknown sources).

Files:
- `index.html` – the current game
- `v1-orbs.html` – earlier version
- `android/source` – Android wrapper source
